# Archytum Website

Public website source for Archytum Technologies LLC.

## Local development

```sh
npm install
npm run dev
```

## Validation

```sh
npm run check
npm run build
npm run validate
```

## Publication boundary

This repository is designed to be public. It must contain only approved website code, public copy, and public assets. Never add business plans, leads, contracts, customer data, tax or banking records, credentials, tokens, `.env` files, or internal run logs.

The Formspree endpoint and Microsoft Bookings URL remain disabled until separately approved and configured. A successful local build is not authorization to publish.
